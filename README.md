查“IPLC 多少钱”的人，通常撞上了两种完全不同的答案：一种是运营商企业专线的报价，按 Mbps 收费、一年起步；另一种是各种“专线 VPS”“机场 IPLC 节点”，每月几十到几百块。两者都叫 IPLC，价格却差出两三个数量级，这篇文章把两个市场拆开说清楚，再以 Mkcloud 这家专线服务商的现售套餐为例，给你一张可以直接对预算的价格表。

## 一条 IPLC 专线的真实价格区间：从每月几百到每月十万+

先给结论：IPLC 的价格取决于你买的是什么形态。

最贵的是运营商裸纤。IPLC 本质是国际私用出租线路，点对点的物理电路，传统电信级报价大约在 500 元/Mbps/月这个量级，私人供应商报价也普遍高于 300 元/Mbps/月。V2EX 上有做过专线生意的用户报过二级市场的行情：200–300 元每兆，而且两端分别收费，还要加上不菲的初装费，合同期通常一年起步。照这个口径，一条 100M 的裸专线，每月成本就是两三万人民币级别，这是大型企业、金融机构才碰的东西。

中间档是专线 VPS。服务商把专线资源切片，做成一台台带独立入口/出口 IP 的 VPS 卖，月付几百到几千元。Mkcloud 的 IPLC 产品就是这个形态：现售套餐 288 元/月起（沪港方向），独享带宽款 650 元/月起，往上按带宽和流量加价。

最便宜的是机场份额。一些机场把一条 IPLC 专线的带宽切成小份卖给个人用户，2023 年前后市面上的 IPLC 份额普遍在每月 15–115 元的档位。便宜，但你买到的只是共享切片，晚高峰体验完全取决于商家有没有超售。

同一条“物理专线”衍化出三种商品，预算自然也分三档。下面重点说中间档，因为搜“IPLC 多少钱”的多数人真正想买的是它。

## IPLC 为什么贵：物理专线、点对点与“不过墙”

IPLC 是 International Private Leased Circuit 的缩写，两端点对点的专用电路。它的核心价值在于跨境段不走公网：数据从国内入口服务器进入专线，直接从境外出口出来，不经过公共国际出口，也就避开了拥堵和干扰最严重的那一段。体现在数字上，就是端内延迟低且稳——香港方向可以做到 1–2ms，上海到香港 21ms，上海到日本 25–28ms。

贵就贵在这个“专”字上。线路资源按容量向运营商采购，成本天然按 Mbps 或按流量摊。IEPL 是它的近亲，二层以太网专线，Mkcloud 家广港方向走的就是 IEPL，同配置下两家价格几乎一样——这点后面表格里能看到。

另外提醒一句：官方资料里的“端内延迟”指入口到出口这段专线的延迟，不等于你家宽带到目标网站的全程耗时。你的本地宽带到入口那一段，仍然是普通公网。

## 决定 IPLC 价格的四个变量

同一家服务商、同一个方向，不同套餐价格能差上百倍，原因就四个：

| 变量 | 具体差异 | 对价格的影响 |
| --- | --- | --- |
| 出口方向 | 香港 / 日本 / 美国，端内延迟 1~134ms 不等 | 线路资源成本不同，香港最便宜，美国最贵 |
| 共享 vs 独享 | 共享按峰值带宽+月流量计费；独享按固定速率计费、不限流量 | 独享起步价通常是共享的 2 倍以上，大带宽独享每月上万 |
| 流量额度 | 计量型套餐按上行+下行双向统计，超量暂停 | 额度翻倍，价格大致翻倍 |
| 配置与接入 | CPU/内存/硬盘，以及是否需要云前置机 | 独享大带宽款标配高配甚至独立服务器，价格跳档 |

双向计费这点值得单独说：你上传 1GB、下载 1GB，额度扣 2GB。估流量预算时别忘了乘二。超量后服务暂停，可以自助购买流量重置，或者提交工单补差价升级套餐。

## 买之前先看这六条：实名、白名单与退款规则

IPLC 类产品是强合规品类，Mkcloud 的购买限制写在购物车页面，都是硬性条件：

1. **实名认证**：需要中国身份信息，注册走“手机验证码+身份证信息+邮箱验证”三重核验，对应《网络安全法》的实名要求。
2. **省级白名单**：直连款只允许绑定省份的 IP 连入（下单时选省份，之后可以改），这是为了防止机场、回国等违规用途。
3. **用途限制**：仅限个人或企业正规用途，禁止机场、回国等用途，违规清退不退款。
4. **出口只出不进**：每台 VPS 的出口 IP 不接受外部连入，不能拿来建公开网站、支付回调或游戏服务端；官方也不承诺 IP 是原生、住宅或流媒体解锁。
5. **退款规则**：仅支持质量问题退款，而且要在开通后 24 小时内提出，工单里要附上具体的延迟、速度数据作为证据；开通后不支持更换地域。
6. **无默认 SLA**：标准产品不附带可用性赔付，金融级场景需要 SLA 得先谈定制；付款目前只支持支付宝。

这几条里最容易被忽略的是第 2 条和第 5 条：人在哪个省就绑哪个省，真要退款就第一时间测速、截图、提工单，别拖过 24 小时。

## 常见问题

**IPLC 最低多少钱一个月？** 分形态：机场份额十几到一百元；专线 VPS 里 Mkcloud 的 IX 款 158 元/月起、常规 IPLC 共享款 288 元/月起；运营商裸纤没有“最低”概念，按 Mbps 计价加初装费。

**机场宣传的 IPLC 为什么只要十几块？** 那是一条专线被切成几十上百份共享的零售份额，和企业独享电路不是同一种商品。份额便宜，代价是晚高峰的不确定性。

**100M 的 IPLC 要多少钱？** 裸纤口径按 200–300 元/M 估算，每月两三万起步；Mkcloud 的 100M 独享 VPS，沪港 7500 元/月、沪美 9000 元/月，沪美 200M 独享 18000 元/月。VPS 与裸纤交付形态不同，价格仅作量级参考。

**IPLC 和 IEPL 哪个便宜？** 在 Mkcloud 这里是同一个价——广港 IEPL 和沪日 IPLC 六个档位价格完全一致。IEPL 是二层以太网专线、IPLC 是点对点电路，民用场景下体验差异不大，按你的入口城市选就行。

**能不能用来建站或当回国线路？** 都不能。出口不支持入站连接，回国属于明确禁止的违规用途，发现了直接清退不退款。

**会有初装费吗？** 运营商裸专线普遍有初装费、一年起签；专线 VPS 形态没有初装费，按月付，升级降级走工单（降级差价不退）。
